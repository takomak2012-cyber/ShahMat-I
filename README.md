# ШахМаты (ShahMat&I)

Android-приложение «ШахМатыиЯ» — удобный и наглядный шахматный тренажёр на русском языке.

<p align="center">
  <strong>Pежимы:</strong> с другом на одном устройстве · с компьютером (3 уровня сложности) · режим обучения
</p>

## Особенности

- **Игра с человеком** — партия на одном экране, ход за ходом.
- **Игра с компьютером** — выберите уровень сложности и сыграйте против встроенного соперника.
- **Подсказки** (3 на партию) — подскажут удачный ход, когда это нужно.
- **Подсветка ходов** — доступные ходы и последний ход всегда наглядно подсвечены.
- **Предупреждение «Вам шах!»** — вовремя заметите угрозу своему королю.
- **Режим обучения** — пошаговые правила, как ходят фигуры (пешка, конь, слон, ладья, ферзь, король).
- **Понятный экран окончания игры** — победа, мат или сдача.
- **Современный дизайн** и плавная анимация (Android Material).

## Жанр и аудитория

Логическая / настольная игра. Подходит новичкам для обучения основам шахмат и
любителям дружеских партий. Возрастная категория 0+.

## Требования к системе

- Android 7.0 и новее
- Свободное место: от 10 МБ (размер APK ≈ 5,1 МБ)
- Интернет не требуется — игра работает офлайн

## Сборка из исходников

Требуется JDK 17+, Gradle wrapper, Android SDK (SDK Manager) с build-tools и target SDK 34.

```bash
# Сборка отладочной версии
.\gradlew.bat assembleDebug

# Сборка релиза (universal APK)
.\gradlew.bat assembleRelease

# Запуск тестов
.\gradlew.bat test
```

Подпись релиза настраивается через `signingConfigs.release` в `app/build.gradle.kts`.
Пароли keystore берутся из переменных окружения
(`SHAHMAT_STORE_PASSWORD` / `SHAHMAT_KEY_PASSWORD`) либо из локального
gitignored-файла `shahmat-signing.properties` (не коммитится). Сам keystore
(`shahmat-release.keystore`) тоже в `.gitignore` — в репозиторий не загружается.

## Структура

```
app/
  src/main/java/com/shahmat/game/
    engine/      — шахматная логика (Board, Move, Piece, ...)
    ui/splash/   — стартовый экран
    ui/select/   — выбор цвета и сложности
    ui/game/     — игровой экран и доска
    ui/learn/    — правила фигур
    ui/gameend/  — экран окончания игры
  src/main/res/  — view/layouts (xml) и ресурсы
  src/test/      — тесты
```
